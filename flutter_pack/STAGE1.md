# InterMove 0.4 — первый этап

Это обновление исходников версии 0.3, а не отдельный Flutter-проект.

## Установка
1. Останови приложение. Сохрани свою текущую папку lib или сделай Git-коммит.
2. Скопируй все 8 файлов из lib архива в lib своего проекта с заменой совпадающих файлов.
3. Скопируй два файла test из архива в свою папку test.
4. В терминале из папки с pubspec.yaml:

```powershell
flutter pub get
flutter analyze
flutter test test/intermove_logic_test.dart test/demo_dispatch_test.dart
flutter run -d windows
```

Новых зависимостей относительно 0.3 нет. Сохрани свои pubspec.yaml, windows и android.
Если ты менял исходники после 0.3, сначала сравни изменения: замена файлов заменит и твои правки.
В версии 0.3 нужны flutter_map, latlong2, url_launcher, http, path, path_provider,
cryptography и sqlite3 3.x. Эта поставка не содержит платформенных папок и pubspec.yaml.

## Что изменилось
- Нижняя панель ограничена шириной 660 на широком окне; карточки компактнее.
- При движении карты поиск сдвигается влево на половину ширины, транспорт — вправо.
  Через 900 мс после последнего движения панели возвращаются. Программное перемещение
  к адресу не запускает скрытие. При отключённых системных анимациях сдвиг мгновенный.
- Параметры коляски, животных, пола водителя и пассажиров находятся в раскрывающемся блоке.
- При включении животных предпочтение пола сбрасывается; выбор пола скрывается.
  В доставке выбора пола также нет.
- Цена пропорциональна расстоянию: 0,70 тенге за метр, округление до двух знаков.
  500 м = 350,00; 501 м = 350,70; 1501 м = 1050,70.
- Такси и автомобильный межгород открывают отменяемый поиск тестового водителя.
  Через пять секунд показан совместимый водитель с минимальным тестовым ETA или no-match.
  Аватары обозначают пол вымышленной записи; используются системные emoji, без внешних изображений.
  Проверяются доступность, число мест, коляска, животные и предпочтение пола.
- Доставка пока сохраняет локальный черновик, как в 0.3.

## Проверка руками
1. Перемещай карту и подожди: обе большие панели должны уйти наполовину и вернуться.
2. Выбери A/B, рассчитай автомобильный маршрут с прежним ключом ORS.
3. Открой дополнительные параметры, выбери женщину. Поиск показывает только женщин.
4. Начни поиск, отмени, начни заново: старый таймер не должен менять новый диалог.
5. Включи животных: выбор пола исчезает и сбрасывается.
6. Коляска + животное + 4 пассажира: подходящей машины нет, параметры не сбрасываются.
7. Коляска + животное + 3 пассажира: вымышленный Данияр на Caddy.
8. Проверь небольшое окно и системный увеличенный текст: панели прокручиваются.

## Границы этапа
Поиск водителя — только визуальная симуляция, без резервирования, оплаты и сохранённого
бронирования. Гостю доступна эта симуляция; реальное демобронирование на следующем этапе
будет требовать входа. ETA водителя тестовый, не вычисляется из его геопозиции.
Полная проверка доступности всех остановок и пересадок ещё не реализована.
Общая база, роли, языки, синтетические автобусные/железнодорожные расписания,
бронирование и уведомления остаются следующими этапами. Старый поиск транспорта
через Overpass пока сохранён; карта трамвая/метро будет заменена по требованиям.
Настройка ключа пока доступна всем: серверных ролей ещё нет.

Flutter SDK в среде подготовки отсутствует. Сборка, анализатор Flutter и Flutter-тесты
здесь не запускались; приложенные тесты не считаются пройденными.
