# InterMove: профиль и поиск адресов

Это обновление предыдущего прототипа из чата. Оно заменяет lib/main.dart и
добавляет три файла. Папки android, windows и ваш pubspec.yaml не заменяются.

## Установка на Windows

1. Останови Flutter (q в терминале). Сохрани текущую версию через Git или скопируй
   старый lib/main.dart за пределы lib.
2. Распакуй архив. Скопируй четыре .dart-файла из его папки lib в папку lib
   твоего Flutter-проекта, заменив main.dart. Не создавай lib/lib.
3. Открой терминал в папке, где находится pubspec.yaml, и выполни:

```powershell
flutter pub add flutter_map latlong2 url_launcher http path path_provider cryptography "sqlite3:^3.7.1"
flutter run -d windows
```

Если pub сообщает, что версия Dart несовместима, пришли вывод flutter --version
и сообщение ошибки. Здесь используется sqlite3 3.x, который включает native assets;
не заменяй его на 2.x без изменения установки.

Если Windows сообщит про symlink support, включи Windows Developer Mode,
как предлагает Flutter, и запусти команду снова.

## Что работает без ключей и регистрации

- Карта OpenStreetMap, перемещение, масштаб, возврат к Актобе.
- Выбор типа транспорта (меняет выбранный вариант, не строит маршрут).
- Точки A/B: выбери поле или значок карты возле него, затем нажми на карту.
- Перестановка точек A/B вместе с подписями, сворачивание панели поиска.
- Кнопка профиля справа сверху: боковая панель шириной 400 пикселей на Windows.
- Регистрация: имя, уникальный логин, пароль от 8 символов, подтверждение пароля.
- После регистрации — автоматический вход и приветствие по имени.
- Выход и повторный вход. Неверный пароль показывает ошибку.
- Кнопка «Продолжить» показывает выбранные точки, но пока не бронирует поездку.

Логин: латинские буквы, цифры, точка, дефис, подчёркивание, 3–40 символов.
Логин не зависит от регистра; пароль зависит, пробелы пароля не удаляются.
После перезапуска приложение снова открывается гостем; аккаунты остаются.

## Настоящие адреса через 2ГИС

1. Открой https://platform.2gis.ru/ и получи ключ с доступом к Geocoder API.
   Доступ и тариф/тестовые ограничения зависят от кабинета 2ГИС.
2. В приложении нажми шестерёнку справа сверху и вставь ключ.
3. Выбери «Откуда» или «Куда», введи город, улицу и номер дома, нажми «Найти адрес»
   или Enter. Поиск отдаёт приоритет окрестностям Актобе.
4. Нажми на результат — координаты попадут в нужную точку, карта приблизится.
5. Для адреса точки сначала выбери её на карте, затем нажми «Адрес точки».
   Сервис может вернуть ближайший объект: проверь результат перед выбором.

При редактировании текста предыдущая выбранная точка очищается: введённый текст
ещё не считается подтверждённым адресом. Выбери результат или точку на карте.
У каждой координаты не обязательно есть почтовый адрес. Отсутствующий адрес
не подменяется выдуманным: можно оставить точку с координатами.

Ключ сохраняется только в памяти до закрытия приложения. Не вставляй его в
исходники и не отправляй в GitHub. Регистрация InterMove не нужна для поиска.
Поиск вызывается кнопкой, а не на каждую букву. Запросы уходят в 2ГИС.
Карта остаётся OpenStreetMap: добавлен API адресов 2ГИС, а не Flutter SDK 2ГИС.
Перед публичным использованием проверь условия выбранного доступа 2ГИС, включая
отображение результатов на сторонней карте; для учебного локального теста это
подключаемая заготовка. API-ключ и реальный ответ сервиса здесь не проверялись.

## База и пароли

База SQLite intermove_local_v1.sqlite автоматически создаётся в папке данных
приложения, определяемой getApplicationSupportDirectory(), вне репозитория.
Таблица users хранит id, имя, нормализованный логин, случайную соль и хеш.
Пароли не записываются открытым текстом. Используется PBKDF2-HMAC-SHA256,
600000 итераций, отдельная соль на аккаунт; расчёт выполняется вне UI isolate.
SQL-запросы параметризованы. Сравнение хеша проверяет все байты.

Это ЛОКАЛЬНЫЕ учебные профили, а не серверная авторизация. На другом компьютере
или телефоне эта база не появится. Изменение локального файла не защищено от
владельца компьютера. Для общих аккаунтов приложения и сайта следующим этапом
понадобится серверный сервис авторизации и общая база; клиенту нельзя доверять
проверку прав доступа. Не используйте этот прототип как авторизацию реального сервиса.

## Структура

- lib/main.dart — карта, кнопки, поля адресов, диалог настройки API.
- lib/profile_panel.dart — форма входа, регистрации, приветствие, выход.
- lib/local_store.dart — SQLite и проверка паролей.
- lib/address_service.dart — запросы к 2ГИС, преобразование ответа в Place.

## Проверка у себя

1. Открой приложение: карта доступна без входа.
2. Создай тестовый профиль. Проверь приветствие с именем.
3. Выйди: проверь неправильный пароль и затем правильный.
4. Попробуй зарегистрировать тот же логин — появится ошибка.
5. Закрой приложение, запусти снова, войди прежним логином.
6. Поставь A/B на карте, поменяй местами, измени текст — старая метка очищается.
7. Подключи ключ: найди известный адрес Актобе, выбери результат.
8. Проверь «Адрес точки», неправильный ключ, отсутствие интернета.
9. Уменьши ширину окна: панель должна перейти вниз и прокручиваться.

Flutter/Dart SDK недоступен в среде подготовки. Выполнена проверка структуры
исходников и SQL-схемы, но flutter analyze, сборка Windows/Android и сетевые
запросы с настоящим ключом НЕ запускались.

Стандартный test/widget_test.dart из flutter create относится к старому счётчику.
Он больше не описывает приложение. Перед flutter analyze/flutter test обнови
его под новую структуру или убери именно этот шаблонный тест; другие тесты
проекта не удаляй. Основной класс теперь InterMoveApp.

## Android позже

Для release-сборки добавь в android/app/src/main/AndroidManifest.xml прямо внутри
<manifest>, перед <application>:

<uses-permission android:name="android.permission.INTERNET" />

Этот код рассчитан на нативные Windows/Android. Для Flutter Web требуется другая
настройка SQLite; Chrome сейчас не является целевой платформой обновления.
